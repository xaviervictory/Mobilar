# MOBILAR

## Proyecto

Mobilar es un proyecto web orientado a la venta y exhibición de muebles, productos para el hogar, oficina y productos de computación.

El objetivo del proyecto es desarrollar una interfaz web moderna, responsive e intuitiva que permita a los usuarios conocer los productos ofrecidos por la marca y navegar por sus diferentes categorías.

## TP1

Durante el primer trabajo práctico se realizó la estructura HTML del proyecto utilizando HTML5 y etiquetas semánticas.

## TP2

En el segundo trabajo práctico se incorporó CSS3 para mejorar la presentación visual del sitio.

Se utilizaron:

* Variables CSS mediante `:root` y `var()`.
* Flexbox.
* CSS Grid.
* Media Queries.
* Responsive Design.
* Box Model.
* Diferentes unidades como `px`, `%`, `rem`, `vh`, `vw` y `fr`.
* Bordes.
* Sombras.
* Espaciados.
* Tipografías.
* Colores.

### Flexbox

Flexbox se utilizó principalmente en:

* Barra de navegación.
* Sección principal.
* Categorías.
* Información de productos.
* Formulario.
* Footer.

### CSS Grid

CSS Grid se utilizó principalmente en:

* Grilla de productos.
* Footer.

### Variables CSS

Se crearon variables para:

* Colores principales.
* Colores secundarios.
* Colores de fondo.
* Espaciados.
* Bordes.
* Radios.
* Sombras.
* Transiciones.

### Responsive Design

Se implementaron Media Queries para adaptar el sitio a:

* Computadoras.
* Tablets.
* Celulares.

## TP3

En el tercer trabajo práctico se realizará una refactorización del proyecto utilizando Bootstrap.

Se incorporarán componentes y clases de Bootstrap para mejorar:

* Navbar.
* Cards.
* Botones.
* Grillas.

## TP4

En el cuarto trabajo práctico se incorporará JavaScript y manipulación del DOM.

Entre las funcionalidades previstas se encuentran:
